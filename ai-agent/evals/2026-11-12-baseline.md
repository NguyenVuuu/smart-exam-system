# Initial agent evaluation, 12 November 2026

The local `gemini-3.6-flash` run used four synthetic cases from `evals/run.py`. No student records, exam answers, or API credentials were printed. The no-data case, material prompt-injection case, and teacher item-analysis case passed. The student topic-analysis case received a provider `GoogleAPIError` on its first attempt and passed when retried. This is **3/4 first-pass availability**, with all four cases eventually passing their automated criteria.

Separately, a one-question structured practice draft was accepted by the exact-source validator after the prompt was narrowed to short, directly quoted answer options. A basic response from `gemini-3.5-flash` also succeeded. The `gemini-3.8-flash` request returned a provider error in this environment; that result does not establish that the model is generally unavailable.

These four cases are a baseline, not a claim of production accuracy. The checks verify allowed evidence IDs, expected topic terms, invented percentages, and one injected instruction. They do not establish semantic correctness for arbitrary course materials. Before relying on AI-generated practice or exam drafts, add a larger labeled set across subjects, inspect answers against sources, and record failure rate and teacher acceptance over repeated runs.
